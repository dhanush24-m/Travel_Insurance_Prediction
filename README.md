# ✈️ Travel Insurance Prediction

A machine learning project to predict whether a customer will purchase travel insurance based on their profile and travel history.

## 🎯 Objective
Build a classification model to predict travel insurance purchase decisions, helping insurance companies target the right customers.

## 📊 Dataset Features
- Age, Employment type, GraduateOrNot
- AnnualIncome, FamilyMembers
- ChronicDiseases, FrequentFlyer
- EverTravelledAbroad
- **Target**: TravelInsurance (0 = No, 1 = Yes)

## 🛠️ Tech Stack
- **Python** — Core language
- **Pandas / NumPy** — Data manipulation
- **Scikit-learn** — ML models
- **Matplotlib / Seaborn** — Visualization
- **Jupyter Notebook** — Analysis environment

## 🧠 Models Used
- Logistic Regression
- Random Forest
- Decision Tree
- XGBoost

## 📈 Workflow
1. 📥 Exploratory Data Analysis (EDA)
2. 🧹 Data Preprocessing & Feature Engineering
3. 🤖 Model Training & Hyperparameter Tuning
4. 📊 Model Evaluation (Accuracy, AUC-ROC, Confusion Matrix)
5. 💡 Key Insights & Recommendations
